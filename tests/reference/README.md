# MATLAB fixtures

`matlab/warp_factory.npz` contains independently exported MATLAB arrays.
`matlab/metadata.json` records the pinned source, runtime and parameters.
`test_matlab_parity.py` runs without MATLAB using these committed fixtures.

See [reference validation](../../docs/reference-validation.md) for reproduction,
CPU compatibility helpers, tolerances and intentional upstream differences.
Never replace reference outputs with values generated by the implementation
under test.
